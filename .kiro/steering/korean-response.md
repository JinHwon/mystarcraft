# 한국어 응답 규칙

- 모든 응답은 반드시 한국어로 작성한다.
- 코드 주석도 가능한 한 한국어로 작성한다.
- 기술 용어는 영어 원문을 병기할 수 있다 (예: 스티어링(steering)).
- 에러 메시지나 로그 등 시스템 출력은 원문 그대로 유지한다.
- 이전 작업 내역이 checkpoint로 저장되어 있으므로, 답변 시 항상 대화 히스토리의 checkpoint 내역을 참고하여 맥락을 유지한다.
- Git 커밋 히스토리에도 checkpoint가 저장되어 있으므로, 필요 시 `git log`를 통해 이전 작업 내역을 확인하고 참고한다.
- 현재 게임은 커리어(시즌) 모드 하나뿐이다. 예전 "내 선수 육성"(연습게임·퀘스트·상점) 모드는 v62.0 에서 제거했다 (todo.md 참고).
